# 결과 읽기

계산이 끝나면 웹의 작업 목록에서 해당 결과를 엽니다.
후보 표에서 행을 누르면 바로 아래 3D 뷰어와 PAE가 바뀝니다.
결과를 전달할 때는 보고서 ZIP을 저장하고, 받은 사람은 ZIP을 풀어 HTML을 엽니다.
기본 작업 폴더는 `.nanocofold/workspace/runs/`입니다. 각 작업의 정확한 경로는
실행 명령 출력과 웹 작업 상세에 표시됩니다.

## 모드별 결과

| 모드 | 결과에서 볼 것 |
|---|---|
| complex | 입력한 체인들의 복합체, 체인 쌍 점수, PAE |
| design | 새 VHH 서열, 생성기 구분, 엔진별 복합체와 선별 여부 |
| screen | 준비한 VHH의 엔진별 예측, 점수, 선별 여부 |
| mature | WT와 생성 변이, 변이 위치, 엔진별 예측 및 WT 대비 차이 |

FASTA는 아미노산 서열, PDB/mmCIF는 3차원 좌표, CSV/XLSX는 표입니다.
PAE는 잔기 사이의 상대 위치에 대한 예측 오차를 나타냅니다.
pLDDT는 국소 구조 신뢰도, ipTM/ipSAE 등은 복합체 인터페이스를 검토할 때 쓰는
예측 지표입니다. 엔진마다 정의·분포가 다르므로 하나의 합산 점수처럼 해석하지 마세요.

**예측 성공**, **선별 기준 통과**, **실험 결합 확인**은 서로 다릅니다.
모델이 생성되어도 선별에 통과하지 않을 수 있습니다. 미평가 값은 0점이 아닙니다.
높은 점수만으로 결합, 친화도 KD, 기능 또는 발현성을 확정할 수 없습니다.

변이 평가의 ESM 서열 점수는 결합 친화도 측정값이 아닙니다. 같은 엔진·조건의 WT와
변이를 비교하고, 후속 실험에 사용할 후보는 전체 서열·구조·실험 조건을 검토하세요.
WT는 대조군으로 남습니다. 발주/실험 인계에 필요한 필드가 없으면 해당 게이트는
통과하지 않습니다. 이를 채우지 않은 상태에서 임의로 통과 처리하지 않습니다.

실패·부분 완료는 보고서에 그대로 남습니다. 로그와 원본을 보존한 뒤 원인을 확인하고,
진행 중인 작업에 같은 입력을 중복 제출하지 마세요.
