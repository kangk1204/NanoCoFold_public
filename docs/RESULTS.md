# 결과 읽기

계산이 끝나면 웹의 **작업·로그**에서 해당 작업의 **결과 열기**를 누릅니다.
후보 표에서 행을 누르면 바로 아래 3D 뷰어와 PAE가 바뀝니다.
결과를 전달할 때는 보고서 ZIP을 저장하고, 받은 사람은 ZIP 전체를 풀어 `report.html`을 엽니다.
처음에는 핵심 지표 열만 보이며 **상세 지표 열 펼치기**로 나머지를 읽습니다. 전체 후보 기록과 실제 모델 기록을 구분합니다. 예측 전 준비·미선정은 모델 평가 미완료에 포함하지 않습니다.
기본 작업 폴더는 `.nanocofold/workspace/runs/`입니다. 각 작업의 정확한 경로는
실행 명령 출력과 웹 작업 상세에 표시됩니다.

입력·MSA·구조·지표·엔진별 순위의 관계는 [분석 과정과 선별 논리](ANALYSIS_WORKFLOW.md)를 참고하세요. 각 결과의 실행 조건과 미평가·실패 상태도 함께 확인합니다.

## 모드별 결과

| 모드 | 결과에서 볼 것 |
|---|---|
| complex | 입력한 체인들의 복합체, 체인 쌍 점수, PAE |
| design | 새 VHH 서열, 생성기 구분, 엔진별 복합체와 선별 여부 |
| screen | 준비한 VHH의 엔진별 예측, 점수, 선별 여부 |
| mature | WT와 생성 변이, 변이 위치, 엔진별 예측 및 WT 대비 차이 |

FASTA는 아미노산 서열, PDB/mmCIF는 3차원 좌표, CSV/XLSX는 표입니다.
PAE는 잔기 사이의 상대 위치에 대한 예측 오차를 나타냅니다.
pLDDT는 국소 구조 신뢰도, ipTM/ipSAE 등은 복합체 인터페이스를 검토할 때 쓰는
예측 지표입니다. 같은 엔진·조건에서 후보를 비교하세요.

모델 생성 후에는 **선별 기준 통과 여부**와 사유를 확인합니다. 미평가 값은 결측으로 남습니다.
선정한 후보의 결합·KD·기능·발현은 후속 실험으로 확인하세요.

변이 평가의 ESM 점수는 서열의 모델상 적합도를 나타냅니다. 같은 엔진·조건의 WT와
변이를 비교하고 전체 서열·구조·실험 조건을 검토하세요. WT는 대조군으로 남습니다.
발주·실험 인계를 진행하려면 해당 검사에서 요구하는 항목을 작성해야 합니다.

실패·부분 완료는 보고서에 그대로 남습니다. 로그와 원본을 보존한 뒤 원인을 확인하고,
진행 중인 작업에 같은 입력을 중복 제출하지 마세요.

일반 complex의 요약 ipSAE는 표시된 체인 쌍의 값입니다. 기본값은 검토 순서의 첫 쌍이며, `complex.primary_pair`를 지정했다면 해당 쌍을 사용합니다. 최댓값·최솟값은 유한한 기록값이 있는 쌍에서 계산합니다. **평가 쌍 수/전체 쌍 수**와 전체 쌍의 표·CSV를 함께 확인하세요. 미평가 쌍은 결측으로 유지합니다.

점수표의 충돌·N/O 근접·반대 전하 접촉은 **원자쌍 수**, 구조의 강조 표시는 중복을 제거한 **잔기쌍**입니다. N/O 근접은 거리로 찾은 후보이며 수소결합 각도 평가를 포함하지 않습니다. 충돌도 설정된 거리 기준을 사용하므로 원소별 반데르발스 판정과 구분합니다.

지표 이름은 기록된 범위를 따릅니다. 일반 복합체의 `whole_complex`는 **전체 복합체 ipTM**, 기록된 `selected_target_binder_pair`는 **표적–VHH ipTM**입니다. 과거 결과에 범위가 없으면 **범위 미기록**, 한 화면에 여러 범위가 있으면 **범위 혼합**으로 표시합니다.

평가가 완료되고 오류가 없으면 오류 칸은 **오류 없음**입니다. 실행하지 않은 모델은 **미평가**, 실패한 모델은 정리된 오류를 표시합니다. 원본 오류 기록은 상세에서 확인합니다.

좌표 출처 안내와 원본 다운로드는 같은 검증 결과를 사용합니다. 원본 파일이 기록된 해시와 일치하면 원본을 내려받을 수 있습니다. 표시용 정렬·재번호가 적용된 경우 원본과 표시 좌표를 구분합니다. 원본이나 검증 근거가 없는 과거 결과에서는 표시 좌표를 저장할 수 있으며, 검증된 원본 다운로드는 제공하지 않습니다.


## PyMOL에서 보기

PyMOL 전용 자료가 제공됐다면 전체 폴더를 압축 해제하고 PyMOL의 **File → Open**에서 `.pml` 파일을 엽니다. 좌표가 내장된 `.pse` 자료를 받았다면 그 파일 하나로 열 수 있습니다. 나노바디 작업 폴더에 생성된 PML 파일 이름은 `05_final/top_candidates.pml`입니다. 폴더를 옮겨도 스크립트와 참조 좌표의 **상대 폴더 구조**를 함께 유지해야 합니다. `.pml`만 따로 복사하거나 좌표 폴더를 삭제하면 구조를 불러올 수 없습니다.

일반 전달용 보고서 ZIP은 HTML에 내장된 좌표를 사용합니다. PyMOL용 자료는 별도로 받아 README에서 열 파일·포함된 모델·좌표 출처를 확인하세요.

## 일반 보고서와 전체 결과 탐색

최신 소스로 저장 run의 일반 `report.html`을 만들면 요약 표 아래에서 전체 모델·관측·PAE를 같은 MolStar 탐색기로 확인합니다. 후보를 선택한 뒤 체인·접촉·충돌 표시, 잔기 선택과 거리 측정을 사용할 수 있습니다. 일반 복합체에서는 VHH 전용 적격·hotspot·CDR 제어가 숨겨집니다. 창 크기를 바꾸어도 수동 회전·확대 상태를 유지하며 **전체 구조 보기**를 누르면 현재 구조를 다시 맞춥니다.

진단용 DataFrame만 제공하거나 저장 결과 탐색 기록이 없으면 표시 범위가 안내된 보조 뷰어를 사용합니다. 이전 HTML은 생성 당시 화면을 유지합니다. 앱에서 보고서를 새로 내보내면 보존된 수치·좌표·PAE를 현재 화면으로 볼 수 있습니다.


입력 검토에 실패한 파일과 로그는 작업 공간의 `inputs/failed_reviews/`에 보관될 수 있습니다. 이 폴더에는 완료 결과의 자동 보존 기한이 적용되지 않습니다. 관리자는 보관할 사본을 확인한 뒤 해당 검토 폴더를 수동 정리할 수 있습니다.
