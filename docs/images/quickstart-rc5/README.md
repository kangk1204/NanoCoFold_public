# rc5 처음 사용 안내용 실제 화면

이 폴더의 기존 이미지는 한국어 화면입니다. [English screenshots](en/README.md)는 `en/` 아래에 별도로 보존하며, 영문 README와 영문 단계 안내에서는 영어 이미지를 연결합니다.

2026-10-15에 실제 브라우저에서 촬영한 JPEG 10개입니다. 이미지 생성, 화면 요소 합성, 수치 편집을 하지 않았습니다. 구조와 PAE는 해당 영역을 실제 캡처했습니다.

입력 화면은 공개 소스 `5a9c3d23e72ec367feac0d1c12377e4c7bec33c1`의 rc5 UI를 macOS의 별도 빈 작업 공간에서 실행했습니다. 공개 예제를 불러오고 단계·언어를 전환했습니다. 공용 MSA 동의 체크박스를 확인했지만 검토·분석 제출 버튼은 실행하지 않았으므로 새 MSA 요청·GPU 예측은 없습니다. 04는 환경 점검 **전** 화면이며 설치 성공이나 제출 승인을 뜻하지 않습니다. 화면은 한국어이며 English로 전환할 수 있습니다.

결과는 앞서 RTX 5070 Ti에서 실제 계산하고 원시 좌표·PAE·점수를 대조한 `e6bf4fc488e85d81b55574f4c1fb8ca1` 작업의 별도 보고서 사본입니다. 계산 소스는 `fe1942e3e4afd202adeadcdb3f03581e982a4151`, 표시 소스는 `6475755c3dc1040da5890671403c9a21600a5b32`입니다. 보고서 사본은 result-data의 원래 바이트를 보존합니다. 이번 촬영에서 다시 예측하거나 재채점하지 않았습니다. 모의 결과가 아니며 생물학적 결합·정확도 검증으로 해석하지 않습니다.
