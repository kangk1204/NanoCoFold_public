# 기존 설치 업데이트

현재 릴리스는 **0.4.8rc10**입니다. 웹 화면과 안내를 업데이트하며 기존 분석을 다시 계산하지 않습니다. 모델 가중치와 예측 엔진을 다시 설치할 필요가 없습니다.

## 1. 실행 중인 작업 마치기

**작업·로그**에서 대기·실행 중인 작업이 없는지 확인합니다. 작업을 중단하려면 **작업 취소**의 확인창에서 확정하고 **취소** 상태가 될 때까지 기다리세요. 이후 웹 서버 터미널에서 **Ctrl+C**를 누릅니다. 원격 서버는 서버 쪽 터미널에서 진행합니다.

## 2. 새 소스 받기

처음 설치한 소스 폴더에서 진행합니다. 설치 기록인 `.nanocofold/`와 작업 공간은 그대로 둡니다. 직접 수정한 소스가 있으면 별도로 보관하세요.

### Git으로 설치한 경우

```bash
git pull --ff-only
```

충돌이나 로컬 변경 때문에 멈추면 메시지를 확인하세요. 소스를 강제로 초기화하지 마세요.

### ZIP으로 설치한 경우

[새 릴리스](https://github.com/kangk1204/NanoCoFold_public/releases/tag/v0.4.8rc10)에서 `NanoCoFold_public-0.4.8rc10.zip`을 받아 **별도 폴더에 압축 해제**합니다. 원래 설치 폴더에서 아래 명령을 실행합니다. 첫 줄의 경로는 방금 압축을 푼 폴더로 바꾸세요.

```bash
update_source="/새로/압축을/푼/NanoCoFold_public-0.4.8rc10"
rsync -a --exclude='.git/' --exclude='.nanocofold/' "$update_source/" ./
```

`--delete`는 사용하지 않습니다. 기존 `.nanocofold/`, 작업 공간과 결과를 유지하며 새 소스 파일을 반영합니다. `rsync`가 없으면 서버 관리자에게 소스 반영을 요청하세요.

## 3. 설치본 갱신하고 다시 열기

같은 원래 설치 폴더에서 실행합니다.

```bash
bash update.sh
bash start.sh --port 18765
```

**Update complete / 업데이트 완료**를 확인한 뒤 시작 명령을 실행하세요. `git pull`만으로 설치된 프로그램이 바뀌지는 않습니다. `update.sh`가 기존 설치 위치의 프로그램을 갱신하며 GPU 계산은 실행하지 않습니다.

브라우저를 새로고침하고 화면 하단의 **v0.4.8rc10**을 확인합니다. 이전 화면이 남으면 **Ctrl+Shift+R**(macOS: **Cmd+Shift+R**)로 다시 불러옵니다. 결과는 **결과 탐색 → 실행 선택**에서 다시 엽니다. 저장된 HTML은 생성 당시 화면을 유지하므로 새 화면이 필요하면 보고서를 다시 내보내세요.

## 업데이트가 멈추면

- 실행 중인 작업이나 웹 서버가 있다는 안내: 해당 작업이 끝난 뒤 같은 명령을 다시 실행합니다.
- 설치 기록을 찾지 못함: 새로 푼 폴더가 아닌 **처음 설치한 폴더**인지 확인합니다.
- 설치 자체가 없는 새 컴퓨터: [설치 안내](../README.ko.md#1-준비와-설치)를 따릅니다.
- 그 밖의 실패: 메시지를 보관하고 원인을 해결한 뒤 `bash update.sh`를 다시 실행합니다. 작업 공간이나 결과를 삭제할 필요는 없습니다.

이번 버전은 현재 적용된 생성 수·평가 수·선별 수를 구분하고 핫스팟 제외 구간의 의미를 안내합니다. 기본 계산 규모와 과학적 선별 기준은 유지합니다.
