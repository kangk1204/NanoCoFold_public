# 공개 배포본의 데이터와 실행 범위

`examples/tutorial`에는 공개 구조 데이터에서 만든 입력 서열과 실행 설정이 있습니다. 서열 출처, 원본 응답 해시, 변환 과정은 `sources.json`에, 배포 파일 해시는 `manifest.json`에 기록합니다. 미리 계산한 예측 결과는 포함하지 않습니다.

- `complex`: barnase–barstar (PDB 1BRS)의 두 단백질 서열.
- `screen`, `mature`, `design`: 사람 IL-6의 성숙 사슬(UniProt P05231, 30–212번 잔기)과 anti-IL6 nanobody(PDB 9VQ6)의 공개 서열. Nanobody는 말단 His-tag를 포함한 기탁 서열을 그대로 사용하며, 9VQ6은 nanobody 단독 구조입니다.
- 브라우저의 CPU 데모와 모의 실행은 합성 구조와 합성 점수를 만듭니다. 실제 엔진 예측이나 결합 실험으로 해석하지 않습니다.

공용 MSA 서비스는 서열을 외부 서버로 전송합니다. 예제 실행 도구는 전송 승인을 명시적으로 받은 경우에만 이를 허용합니다. 실제 연구 입력을 사용할 때도 전송할 서열과 기관의 데이터 취급 조건을 먼저 확인하세요. 승인 없이 자동으로 외부 검색으로 전환하지 않습니다.

특정 컴퓨터의 계정이나 원격 MSA 검색 서버는 사전 등록되어 있지 않습니다. `local_mmseqs2` 전용 원격 검색은 관리자가 별도로 등록하기 전까지 오류로 중단됩니다. 공개 예제는 명시적 승인을 받는 API 경로를 사용합니다. 검증된 로컬 MSA 캐시도 사용할 수 있습니다.

설치 프로그램은 고정된 버전과 파일 해시로 외부 도구 및 모델을 내려받고, 설치된 컴퓨터에서 준비 상태를 확인합니다. 저장소에는 모델 가중치, 설치된 가상환경, 실행 결과, 사용자 입력이나 인증정보를 넣지 않습니다. 외부 도구의 고지는 `LICENSE_MANIFEST.md`와 `assets/*LICENSE.txt`를 참고하세요.

예제의 입력 검토와 CPU 회귀 시험은 GPU 추론 성공을 의미하지 않습니다. 예측이 완료되어도 신뢰도 점수나 선별 통과는 실제 결합·친화도·발현 검증을 대신하지 않습니다.
