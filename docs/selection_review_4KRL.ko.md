# EGFR–7D12 선별 기준 검토

검토일: 2026-11-10. 대상: 보존된 4KRL 실험의 CDR3 4개 치환 변이 200종과 WT 1개. 새 예측이나 재선별은 하지 않았습니다.

## 판단

현재 기준은 탐색적 후보 우선순위와 수동 검토를 위한 기준으로 사용할 수 있습니다. 이 표적의 결합 여부를 판정하는 검증된 분류기로 해석할 근거는 부족합니다. 기준을 낮추거나 기존 판정을 변경할 근거도 이번 결과만으로는 없습니다.

201개 모델의 계산은 완료됐습니다. 변이 6종은 구조 기준을 통과했지만 서열 검토 보류이며, 194종은 구조 기준 미통과도 동반합니다. 최종 선별 0종은 정상적으로 기록된 결과입니다. 플랫폼은 엔진의 예측값과 설정된 선별 규칙을 함께 적용하므로, 선별 수는 두 요소를 모두 반영합니다.

## 유지한 기준과 해석

| 항목 | 실행 기준 | 해석 |
|---|---:|---|
| ipSAE | ≥0.6 | PAE 기반 인터페이스 신뢰도. 본 실험에서 보정된 결합 확률이 아닙니다. |
| 체인쌍 ipTM | ≥0.7 | 표적–VHH 구조 예측 신뢰도. 전체 복합체 ipTM과 구분합니다. |
| 인터페이스 pLDDT | ≥70 | 국소 구조 신뢰도. 플랫폼의 0–100 척도를 사용합니다. |
| 원자 충돌 | 0 | 기록된 충돌 정의에 따른 구조 점검입니다. |
| 서열 검토 항목 | 최대 1개 | 초과 시 검토 보류. 실험적 발현·안정성 실패 판정은 아닙니다. |
| 결합 부위 필수 | 꺼짐 | 지정 부위 접촉은 진단값으로 보존하며 새 선별 조건을 추가하지 않았습니다. |

ipSAE는 PAE 절단값과 유효 잔기에 의존하는 점수입니다. 특정 점수 하나를 모든 표적·구축체에 공통인 결합 판정값으로 쓰는 것은 원래 정의보다 강한 해석입니다. [ipSAE 공식 구현](https://github.com/DunbrackLab/IPSAE)

Boltz의 구조 신뢰도 출력과 affinity 출력은 별개입니다. 공식 affinity 기능의 지원 대상은 단백질–소분자이며, 여기의 나노바디 점수를 KD로 변환하지 않습니다. [Boltz 공식 예측 문서](https://github.com/jwohlwend/boltz/blob/main/docs/prediction.md)

## WT 대조와 공통 서열 항목

4KRL은 EGFR 도메인 III–7D12 실험 복합체입니다. 원본 구조의 label chain과 author chain은 서로 다릅니다. 이번 비교는 author A=EGFR, B=7D12의 명시적 대응을 사용합니다. [RCSB PDB 4KRL](https://www.rcsb.org/structure/4KRL)

저장된 WT 예측은 ipSAE 0.518로 기준에 못 미치지만, 표적 정렬 후 실험 접촉 42개 중 37개를 회복했습니다. 이는 알려진 결합체도 이번 단일 예측·선별 조합에서 통과하지 않을 수 있음을 보여줍니다. 이를 근거로 모든 변이가 비결합체라고 결론 내리거나, 0.518에 맞춰 기준을 사후 조정하지 않습니다.

모든 변이는 WT에서 유지된 CDR2 DS 모티프와 CDR 경계에 걸친 선형 소수성 구간 때문에 공통 검토 항목을 가집니다. 현재 v2 정책은 이를 검토 보류로 처리합니다. 동일 항목은 WT와 변이에 같은 규칙으로 적용되고, 구조적 매몰이나 실제 응집·분해를 직접 측정한 값으로 표시하지 않습니다. 이번 점검에서 수치나 판정 논리를 바꿔야 할 오류는 확인하지 못했습니다.

6종의 구조 기준 통과가 WT 결합 자세의 회복을 뜻하지는 않습니다. 이들의 WT 접촉 회복률은 0–28.6%였으며, WT 참조 구조는 비교용으로만 연결했습니다. 변이의 실험 구조는 알려져 있지 않아 WT와 다른 자세 자체를 오류로 판정하지 않습니다.

## 비교 범위

같은 WT에서 파생된 200종, 공유 상동 서열, 단일 seed 42 결과입니다. 독립적인 200개 표적 검증으로 집계하지 않습니다. MSA는 공개 표적과 WT를 검색한 뒤 변이별 query만 교체했으며, 변이별 독립 검색은 하지 않았습니다. API 데이터베이스 revision은 제공되지 않아 미기록으로 유지합니다.

운영 용도의 결합 분류 성능을 주장하려면 별도 양성·음성 실험군과 미리 고정한 판정 기준으로 평가해야 합니다. 이는 현 결과의 전달을 막는 조건이 아니라, 이후 성능 주장의 범위입니다. 이번 변경은 경고 번역·출처 연결·무손실 보고서 압축에 한정하며 원본 점수·순위·선별 기준·결과를 보존합니다.
