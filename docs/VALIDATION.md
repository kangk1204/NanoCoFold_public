# 배포 검증 기록

## v0.4.2 설치 조건 검증

2026-10-10, Ubuntu 세부 버전의 고정 목록을 제거하고 실제 환경 요구 사항 검사는 유지했습니다.

- 공개 CPU 회귀 시험: **145건 통과, 실패 0**. Ubuntu 25.10·이후 버전의 호스트 검사 진입과 다른 OS·CPU 아키텍처·NVIDIA 오류 차단, glibc·필수 도구 검사를 포함합니다.
- 실제 Ubuntu 25.10 x86_64 / RTX 5070 Ti / 드라이버 595.71.05에서 변경된 `bash install.sh --check-host --gpu GPU-…`가 **exit 0**으로 종료했습니다.
- 이 실제 검사는 읽기 전용입니다. 새 설치·sudo/apt·MSA 전송·GPU 추론을 실행하지 않았으며, 진행 중인 v0.4.1 시험의 원본 소스 SHA를 그대로 확인했습니다.

Ubuntu 버전 번호를 허용하는 것은 모든 버전·GPU 조합의 설치와 추론이 검증됐다는 뜻이 아닙니다. v0.4.2의 분석 로직·점수 정책·예제·엔진 조건은 v0.4.1과 같습니다.

## v0.4.1 문서·화면 검증

2026-10-10, 공개 웹 애플리케이션을 새 작업 공간에서 실행해 실제 Chromium 화면 4장을 촬영했습니다.
네 모드의 공개 JSON을 웹 UI에서 각각 업로드하고, 입력 검토 완료·미제출 상태를 확인했습니다.
실행한 작업은 화면 안내용 CPU 데모 1개이며 실제 GPU 예측과 MSA 전송은 없었습니다.
결과 화면의 `MOCK · 실제 예측 아님` 표시는 유지했습니다.

캡처 환경은 macOS의 Chromium입니다. 이를 Ubuntu GPU 추론 검증으로 해석하지 않습니다.
캡처 과정의 외부 요청·JavaScript 오류는 0건입니다.
[이미지별 출처·SHA256](images/README.md)을 함께 제공합니다.
공개 회귀 시험은 CPU 실행 계약을 포함하여 **127건 통과, 실패 0**입니다.
이번 버전은 문서와 버전 표기만 변경하며 분석 로직·설치기·입력·점수 정책은 아래 0.4.0과 같습니다.

## v0.4.0 검증 기록

검증일: 2026-10-10. 아래는 이 공개 배포본에서 실제 확인한 범위입니다.

|---|---|
| 공개 회귀 시험 | Python 3.12에서 **127건 통과, 실패 0**. 설치기, 공개 서열·해시, API 전송 동의, 중복 제출 방지, 보고서 데이터 보존, CPU 실행 계약 포함 |
| 네 모드 입력 | 각 모드를 실제 CLI `batch review`로 검토해 모두 통과. 이 단계는 계산을 제출하거나 서열을 전송하지 않음 |
| Linux CPU 설치 | Ubuntu 26.04 x86_64의 새 격리 작업 공간에서 `--profile core --skip-system-packages` 설치와 같은 작업 공간의 반복 설치 성공. 고정 uv/Python 준비, 25개 패키지 의존성 검사, 핵심 import, core 준비 상태 확인 |
| 설치된 Linux 프로그램 | 소스와 설치 코드·템플릿 100개 SHA 일치. `run_example.sh` 네 모드 입력 검토 4/4 성공, `start.sh` 웹 화면·자산·인증 API 6개 HTTP 200. 계산 작업 생성 0건, 점검용 웹 프로세스 종료 확인 |
| CPU 실행 계약 | screen/mature/design의 **합성 데이터** 실행과 보고서 ZIP 생성 확인. complex는 합성 좌표 생성을 거부하고 실패 상태·오류 보고서를 보존함을 확인 |

| 패키징 | 비편집 wheel 생성과 공개 예제·설정·외부 도구 고지 포함 확인 |
| 공개 범위 | 소스·배포 파일의 과거 연구 서열, 결과, 개인 서버 설정과 인증정보 혼입 검사. 기존 Git 이력은 가져오지 않음 |

이 검증에서는 GPU 시험 서버의 NVIDIA 드라이버/라이브러리 불일치 때문에 **새 공개 예제의 실제 GPU 추론을 수행하지 못했습니다.** 따라서 네 예제의 실제 예측 성공, 정확도, 소요 시간이나 특정 GPU 기종의 지원을 검증했다고 주장하지 않습니다.

빈 Ubuntu에서 `apt`부터 여덟 엔진·모델을 전부 새로 받는 설치는 이번에 실측하지 않았습니다. 실제 Linux 검증은 시스템 패키지를 이미 갖춘 컴퓨터의 **core 프로필**에 한정됩니다. 기본 `all` 설치의 순서·자원 잠금·도구 준비·오류 처리에는 회귀 시험을 적용했으며, 실제 대상 컴퓨터에서 CUDA 연산과 자산 해시까지 통과해야 설치 완료를 기록합니다.

합성 점수·입력 검토·설치 확인은 과학적 예측 결과가 아닙니다. 실제 예측이 완료되더라도 결합·KD·발현은 별도 실험이 필요합니다. 첫 실행은 가장 작은 `complex` 예제로 시작하고, 결과의 완료·실패·미평가 상태를 확인하세요.

저장소 CI는 Ubuntu 22.04/24.04에서 CPU 회귀 시험과 wheel 빌드를 실행하도록 구성되어 있습니다. 각 릴리스의 실제 CI 결과는 GitHub Actions에서 해당 태그와 커밋을 확인하세요. CI를 설정한 것만으로 실행 성공을 주장하지 않습니다.
