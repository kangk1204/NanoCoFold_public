설정 저장 실패와 파생 내보내기 실패를 구분하고 계산 당시 설정·표·성공 관측·실패 이력을 보존합니다. Unicode/괄호 후보 ID도 원본 이름을 유지한 채 안전한 PyMOL 별칭으로 전달합니다. 예측 전 준비 후보와 실제 모델의 집계, 다중 체인의 표적–결합자 ipTM, ipSAE 체인쌍 범위, 미평가 CDR·특이성·서열 coverage, CSV BOM·공개 오류·경로 정리를 회귀 검사했습니다. DMS에서 사용하지 않는 `size`와 실제 `max_variants` 한도는 검토 단계에서 알립니다.

원본 전체 ZIP은 로컬 복구·보관용이며 실행환경 경로와 로그를 포함합니다. 공동연구자에게는 **전달용 보고서 ZIP**을 보냅니다. 과거 v0.4.1 공개 예제는 `examples/outputs`, 최신 수정 코드의 primary 결과 및 별도로 표시한 이전 rc1 보조 사례는 `examples/current_native`에서 읽습니다. 입력·계산 소스·실제 조건·표시 revision을 구분합니다.

공용 MSA API·모든 입력 길이·GPU·OS 조합, 운영 원격 agent 전체 업데이트, 독립 초보자 참여 시험, 접근성 인증, 실험 결합·KD·발현과 예측 정확도/우월성은 이 소프트웨어 검사로 확립되지 않았습니다. 기준을 낮춰 선별 수를 늘리지 않으며, 완료·적격·선정·실험 결합을 구분합니다.

## v0.4.3 NVIDIA 오류 표시 검증

2026-10-10, 설치 전 GPU 점검에서 숨겨졌던 원본 오류를 표시하도록 수정했습니다.

- 공개 CPU 회귀 시험: **157건 통과, 실패 0**. 새 12건은 원본 오류가 stdout/stderr에 쓰이거나 아예 없을 때, exit18/255 및 기본 설치/읽기 전용 점검을 확인합니다. 설치 전 중단과 기존 종료 코드를 보존합니다.
- 수정 전 v0.4.2 코드에서 새 12건은 모두 실패했고 수정 후 모두 통과했습니다.
- 실제 Ubuntu26.04의 드라이버/라이브러리 불일치 장비에서 원본 v0.4.2는 exit18·빈 출력이었고, 별도 임시 폴더의 수정 설치기는 같은 exit18 및 `Driver/library version mismatch` 원본 메시지를 표시했습니다. 시스템의 재부팅 필요 상태도 확인했습니다.
- 원본 소스 파일 SHA, 드라이버, 시스템 패키지 및 기존 설치 상태는 변경하지 않았습니다. 이 검사는 GPU 드라이버 문제를 해결하거나 설치 완료를 인증한 것이 아닙니다.

분석 코드·점수·공개 예제·모델 조건은 v0.4.2와 같습니다. 기존 결과를 다시 계산할 필요는 없습니다. 별도 공개 예제의 실제 GPU 실행과 보고서 감사는 이 호스트 오류 표시 검사와 구분합니다.

2026-10-10, Ubuntu 세부 버전의 고정 목록을 제거하고 실제 환경 요구 사항 검사는 유지했습니다.

이 검증에서는 GPU 시험 서버의 NVIDIA 드라이버/라이브러리 불일치 때문에 **새 공개 예제의 실제 GPU 추론을 수행하지 못했습니다.** 따라서 네 예제의 실제 예측 성공, 정확도, 소요 시간이나 특정 GPU 기종의 지원을 검증했다고 주장하지 않습니다.

빈 Ubuntu에서 `apt`부터 여덟 엔진·모델을 전부 새로 받는 설치는 이번에 실측하지 않았습니다. 실제 Linux 검증은 시스템 패키지를 이미 갖춘 컴퓨터의 **core 프로필**에 한정됩니다. 기본 `all` 설치의 순서·자원 잠금·도구 준비·오류 처리에는 회귀 시험을 적용했으며, 실제 대상 컴퓨터에서 CUDA 연산과 자산 해시까지 통과해야 설치 완료를 기록합니다.

합성 점수·입력 검토·설치 확인은 과학적 예측 결과가 아닙니다. 실제 예측이 완료되더라도 결합·KD·발현은 별도 실험이 필요합니다. 첫 실행은 가장 작은 `complex` 예제로 시작하고, 결과의 완료·실패·미평가 상태를 확인하세요.

저장소 CI는 Ubuntu 22.04/24.04에서 CPU 회귀 시험과 wheel 빌드를 실행하도록 구성되어 있습니다. 각 릴리스의 실제 CI 결과는 GitHub Actions에서 해당 태그와 커밋을 확인하세요. CI를 설정한 것만으로 실행 성공을 주장하지 않습니다.
