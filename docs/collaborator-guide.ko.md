# NanoCoFold 공동연구자 안내

NanoCoFold는 표적 단백질에 대한 나노바디 후보를 설계하고, 예측 구조와 서열 특성을 비교하는 프로그램입니다. 처음에는 공개 예제로 설치부터 결과 확인까지 진행해 주세요. 받은 결과만 확인하려면 [ZIP 열기](#5-zip-열기와-결과-전달)부터 보시면 됩니다.

- [GitHub](https://github.com/kangk1204/NanoCoFold_public)
- [한글 README](../README.ko.md) · [English README](../README.md)
- [한글 단계별 그림](browser_quickstart.md#그림으로-따라-하기)

## 플랫폼은 어떻게 작동하나요?

새 나노바디 설계의 기본 흐름입니다. 백본은 단백질의 3차원 골격이고, 서열은 그 골격을 구성할 아미노산의 순서입니다.

**표적·scaffold → 후보 생성 → 선택한 사전 평가·CDR 치환 → 복합체 구조 예측 → 평가·선별 → 보고서**

1. **입력 준비:** 표적 단백질과 나노바디 기본 골격(scaffold)을 선택합니다. 원하는 결합 부위가 있으면 표적 잔기를 지정합니다.
2. **후보 생성:** RFantibody, BoltzGen 또는 두 도구를 모두 선택합니다.

   | 생성 도구 | 처리 순서 |
   |---|---|
   | RFantibody | RFdiffusion으로 백본 생성 → ProteinMPNN으로 서열 설계 → RF2로 구조 확인 |
   | BoltzGen | 구조 설계 → 구조에 맞는 서열 설계(역접힘) → 재접힘·분석 |

   두 도구를 모두 선택하면 각각 후보를 생성한 뒤 모아서 평가합니다.
3. **후속 구조 예측:** 선택한 ColabFold·Boltz-2·Chai-1·OpenDDE 엔진으로 후보와 표적의 복합체 구조를 예측합니다. 사용할 엔진과 단계별 선별 경로는 실행 조건에서 정합니다.
4. **평가와 선별:** ipTM·ipSAE, pLDDT·PAE, 결합 부위 접촉, 원자 충돌, 서열의 개발가능성을 확인합니다. 같은 엔진·조건 안에서 후보를 비교하고, 적격 기준과 CDR3 다양성 제한에 따라 선별합니다.
5. **결과 확인:** 후보 표 → 3D 구조·PAE → 제외·미평가 사유 → 서열·점수·보고서 다운로드 순서로 검토합니다. 최종 후보는 후속 실험에 사용할 검토 목록으로 활용합니다.

설정에 따라 생성 후보의 CDR 치환 서열을 추가하거나 ESM·AntiFold 사전 평가를 사용할 수 있습니다.

| 분석 목적 | 출발점과 결과 |
|---|---|
| 단백질 복합체 예측 | 입력한 단백질들의 복합체 구조 예측 |
| 새 나노바디 설계 | 표적과 scaffold에서 새 후보 생성·평가 |
| 보유 나노바디 비교 | 입력한 VHH 서열들을 같은 표적에 대해 평가 |
| 기존 나노바디 변이 평가 | 기존 VHH의 CDR 치환 후보를 만들고 원형과 비교 |

## 1. 설치 파일 받기

GitHub에서 **Code → Download ZIP**을 누르고 전체 압축을 풉니다. `README.md`, `install.sh`, `start.sh`가 있는 폴더를 연 뒤, 그 폴더에서 터미널을 엽니다.

새 설치는 NVIDIA GPU가 있는 Ubuntu x86_64 컴퓨터에서 진행합니다. 첫 네 엔진 예제의 기준은 GPU 메모리 16 GB, RAM 32 GB, SSD 여유 공간 150 GiB 이상입니다. 운영체제·드라이버 조건은 [README](../README.ko.md#1-준비와-설치)에서 확인하세요. Windows·macOS에서는 설치된 서버에 접속하거나 받은 보고서를 열 수 있습니다.

## 2. 설치하기

다음 명령을 하나씩 실행합니다. 각 명령이 `[설치 완료]`로 끝난 뒤 다음 명령을 실행하세요. 첫 설치에서는 엔진과 모델 파일을 내려받습니다.

```bash
bash install.sh --profile complex
bash install.sh --profile colabfold
bash install.sh --profile opendde
```

GPU가 여러 개이면 README의 **여러 GPU** 안내에 따라 사용할 GPU를 지정하세요. 메모리가 16 GB 미만이면 관리자와 엔진·입력 크기를 정해 주세요. 새 나노바디 설계와 변이 평가까지 사용하려면 README의 **전체 환경 설치** 안내를 따라 주세요.

## 3. 화면 열기

설치한 컴퓨터의 같은 폴더에서 실행합니다.

```bash
bash start.sh --port 18765
```

터미널의 **NanoCoFold:** 뒤에 표시된 주소를 브라우저로 엽니다. 위 명령의 기본 주소는 [http://127.0.0.1:18765](http://127.0.0.1:18765)입니다. 화면 상단에 **NanoCoFold**가 표시되면 **Language → 한국어**를 선택합니다. 사용하는 동안 서버 터미널은 열어 두세요.

원격 서버를 내 PC에서 사용할 때는 아래 두 터미널을 모두 열어 둡니다.

**서버 터미널:**

```bash
bash start.sh --no-browser --port 18765
```

**내 PC 터미널:** `USER@SERVER`를 관리자가 알려준 계정과 서버 주소로 바꿉니다.

```bash
ssh -o ExitOnForwardFailure=yes -L 18765:127.0.0.1:18765 USER@SERVER
```

연결되면 내 PC 브라우저에서 [http://127.0.0.1:18765](http://127.0.0.1:18765)를 엽니다. 다른 포트가 필요하면 README의 원격 접속 안내를 따라 주세요.

## 4. 첫 분석 실행하고 결과 보기

1. **처음 한 번 환경 확인**에서 **단백질 복합체 예측**을 선택하고 **환경 확인 시작**을 누릅니다.
2. **환경 확인 완료**가 나오면 **분석 준비하기**를 누릅니다.
3. **이 목적의 공개 예제 불러오기**를 누릅니다. Barnase 110 aa와 Barstar 89 aa, 사본 각 1개가 채워집니다.
4. **입력 확인 후 다음**을 누릅니다. 작은 시작 설정, 엔진 4개, 계획 4모델을 확인합니다.
5. 공용 MSA의 예제 서열 전송에 동의한 뒤 **조건 확인 후 다음 → 입력 확인 → 분석 실행**을 한 번 누릅니다.
6. **작업·로그**에서 방금 제출한 분석을 고르고 완료를 기다립니다. 완료 후 **결과 열기**를 누릅니다.

결과 화면의 완료·실패·미평가 모델 수를 먼저 확인하세요. 표에서 후보·모델 행을 선택하면 점수, 3D 구조와 PAE가 표시됩니다. **결과 탐색 → 실행 선택**에서도 저장된 분석을 다시 열 수 있습니다.

`diagnostics · 완료`는 환경 확인 기록입니다. 다음 단계는 **분석 준비하기**입니다. 결과 버튼이 보이지 않으면 작업 상세 아래로 내려가 확인하세요.

공개 예제를 마친 뒤에는 연구 목적을 고르고 본인의 아미노산 서열을 입력합니다.

## 5. ZIP 열기와 결과 전달

GitHub의 **Download ZIP**은 설치용 소스입니다. 아래의 샘플 ZIP은 별도로 전달하며, `START_HERE.html`은 통합 샘플 ZIP과 complex 샘플 ZIP에 들어 있습니다.

받은 ZIP **전체를 압축 해제**한 뒤, 생성된 폴더에서 아래 파일을 엽니다.

| 받은 파일 | 여는 방법 |
|---|---|
| 공동연구자용 통합 ZIP | `START_HERE.html` → 원하는 모드의 **보고서 열기** |
| screen·mature·design 개별 샘플 ZIP | `report.html` |
| complex 샘플 ZIP | `START_HERE.html`에서 mock 실행 거부 기록 확인 |
| 분석 후 내려받은 전달용 보고서 ZIP | `report.html` |

첨부 샘플은 CPU/mock 예제입니다. 보고서 상단 **Language**에서 한국어와 영어를 전환할 수 있습니다. 보고서와 관련 파일은 압축을 푼 폴더 구조 그대로 보관하세요. 저장된 보고서는 Windows·macOS의 웹브라우저에서도 열 수 있습니다.

본인의 분석 결과를 공유할 때는 **전달용 보고서 ZIP**을 내려받아 ZIP 전체를 보내 주세요. 표는 CSV/XLSX, 서열은 FASTA, 구조는 좌표 파일로 저장할 수 있습니다.
