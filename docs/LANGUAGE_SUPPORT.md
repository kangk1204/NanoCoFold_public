# English / Korean support · 한영 사용 안내

The [English README](../README.md) and [한글 README](../README.ko.md) follow the same installation and analysis steps.

영어와 한글 README는 같은 설치·분석 순서를 안내합니다.

| Item / 항목 | How it works / 사용 방법 |
|---|---|
| Browser / 웹 화면 | Starts in English. Use **Language → English / 한국어** in the header. / 처음에는 영어로 열립니다. 상단에서 언어를 선택하세요. |
| Saved preference / 언어 저장 | The browser remembers your choice when local storage is available. / 브라우저에서 저장 기능을 사용할 수 있으면 선택한 언어를 기억합니다. |
| Direct link / 직접 링크 | Add `?lang=en` or `?lang=ko` to select the language for that URL. / 주소에 `?lang=en` 또는 `?lang=ko`로 언어를 지정할 수 있습니다. |
| Interactive report / 대화형 보고서 | Newly exported reports include the same selector and work offline. / 새로 내보낸 보고서는 같은 언어 선택기를 제공하며 오프라인에서 열립니다. |
| Older report / 이전 보고서 | Export a new report from the app for the current bilingual interface. Keep the older archive. / 현재 한영 화면이 필요하면 앱에서 보고서를 다시 내보내고 이전 원본도 보관하세요. |

Switching language updates labels, instructions, messages, charts and metric captions. Your selected candidate and inputs stay in place while analysis continues. Candidate IDs, protein names, sequences, coordinates, numerical results, original settings and raw logs remain as recorded.

언어를 바꾸면 버튼·설명·메시지·차트·지표 이름이 바뀝니다. 선택한 후보와 입력은 유지되고 분석은 계속됩니다. 후보 ID·단백질 이름·서열·좌표·수치·원본 설정·실행 로그는 기록 그대로 표시합니다.

Technical documents, terminal output and browser or operating-system dialogs may use their original language. For software and browser checks, see the [validation record](VALIDATION.md).

기술 문서·터미널 출력·브라우저와 운영체제 대화상자는 원래 언어로 표시될 수 있습니다. 소프트웨어와 브라우저 검사 결과는 [검증 기록](VALIDATION.md)을 확인하세요.
