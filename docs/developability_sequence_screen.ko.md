# 서열 기반 개발가능성 검토

[English](developability_sequence_screen.md)

정책: `sequence_liability_screen_v2`. 새로 계산한 서열 평가에 적용합니다. 기존 결과를 열 때 다시 판정하지 않습니다.

## 이 검사가 의미하는 것

이 검사는 실험적 개발가능성을 예측하도록 보정된 모델이 아닌 서열 검토 도구입니다. 모티프는 검토할 가능성을 표시하며, 실제 분해·응집·발현량 저하·결합 소실을 확정하지 않습니다. LAP 연구는 모티프만 검사할 때 생기는 과잉 검출과 구조적 맥락의 중요성을 설명합니다([LAP, 2024](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1011881)).

TAP는 구조 표면 특성과 임상 단계 항체의 분포를 사용합니다. NanoCoFold의 5잔기 Kyte–Doolittle 평균과 같은 지표가 아닙니다([TAP, 2019](https://pmc.ncbi.nlm.nih.gov/articles/PMC6410772/)). 나노바디에 특화된 TNP도 측정 방식과 분자 형식의 영향을 받는 검토 도구입니다([TNP, 2026](https://pmc.ncbi.nlm.nih.gov/articles/PMC12963540/)). NanoCoFold가 TAP·TNP를 구현하거나 그 기준으로 보정됐다는 뜻은 아닙니다.

## 분류 수정

| 검출 모티프 | v2 분류 | 이전 분류 |
| --- | --- | --- |
| NG, NS | 탈아미드화 검토 | 유지 |
| DG, DS | Asp 이성질화 검토 | 탈아미드화에 잘못 포함, DG는 중복 집계 가능 |
| DP | 절단 가능성 검토 | 이성질화에 포함 |

기존 설정을 읽더라도 같은 위치의 같은 반응 항목은 한 번만 집계합니다. 같은 항목에 모티프가 여러 개 있어도 `dev_severe`에는 항목 하나로 계산합니다. 원래 설정 이름, 모티프, 위치와 CDR 영역은 `dev_motif_evidence`에 남깁니다. Asn/Asp 이외의 사용자 지정 모티프는 설정된 검토 이름을 유지하고 `chemistry_assigned=false`로 기록합니다.

`dev_severe`는 호환성을 위해 유지한 필드명입니다. v2에서는 Cys 개수, 당화 모티프, CDR 탈아미드화, CDR 이성질화, CDR 절단, CDR와 겹치는 소수성 창의 6개 검토 항목을 셉니다. 실제로 확인된 심각한 결함의 개수가 아닙니다. `dev_flags`는 여기에 산화·pI·전하 항목을 더해 상대 순위에 사용합니다.

기존 Cys·당화 필드명은 유지합니다. Cys 개수만으로 자유 Cys를, 당화 모티프만으로 실제 당화를 확정하지 않습니다. 소수성 기록은 기준을 넘은 연속 서열 창을 합친 구간과 CDR 중첩을 보여줍니다. 구조 표면의 소수성 패치 점수가 아닙니다.

## 선별 방식

- `screen_pass`: CDR 세 영역을 평가했고 항목 수가 설정 상한 이내입니다. 구조 등 다른 선별 기준도 통과해야 합니다.
- `review_required`: 항목 수가 상한을 넘었습니다. `final_eligible=false`, 사유는 `developability_review_required`입니다. 검토를 위해 자동 선별을 보류합니다.
- `unassessed`: CDR 주석이 없거나 유효하지 않습니다. 검토 항목 0건과 다릅니다.

기본 상한 `rank.max_dev_severe: 1`, 소수성 창 5잔기·KD 평균 1.6, Cys 상한 2는 그대로입니다. 이번 후보에 맞춰 기준을 조정하지 않았습니다. 이 수치는 검토를 위한 운영 기준이며 임상적 실패 경계로 검증된 값은 아닙니다.

원본 서열과 공통인 항목도 자동 면제하지 않습니다. 변이·구조·발현 형식에 따라 영향이 달라질 수 있습니다. 구조 예측이 양호한 후보도 개발가능성을 별도로 검토해야 합니다. `fallback_to_ineligible`이나 `dev_flags` 가중치 0은 v2 검토 보류를 해제하지 않습니다. 합성 목록 생성과 전달 검증에서도 보류를 유지합니다.

기존 점수·항목·판정·파일은 보존합니다. 새 평가는 별도 정책과 결과로 기록하며, 정의가 다른 v1·v2 항목 수를 같은 척도로 합치지 않습니다. 이번 수정은 수동 승인 우회, WT 면제 또는 실험적 적격 승인을 추가하지 않습니다.
