# 저장된 분석의 점수 다시 계산하기

`score`는 저장된 예측으로 지표와 선별 결과를 다시 계산합니다. 예측 엔진을 새로 실행하지 않습니다. `report`는 저장된 결과 표로 보고서만 다시 만듭니다.

원본 분석 폴더를 보관하세요. 다른 점수 설정을 비교하려면 폴더 전체를 새 위치에 복사한 뒤 사본에서 `score`를 실행합니다. 재현성을 확인할 때는 같은 설정을 사용하고, 다른 판정을 의도할 때만 점수 설정을 바꾸세요.

```bash
nanocofold score --run-dir /path/to/analysis-copy
nanocofold report --run-dir /path/to/analysis-copy
```

| 메시지 | 조치 |
|---|---|
| 예측 단계 구성이 기록과 다릅니다 | `score`는 다른 모드·엔진 비교·단계별 평가에 필요한 예측을 만들지 않습니다. 새 폴더에서 해당 분석을 먼저 실행하세요. |
| 기록된 예측 목록이 없거나 변경됐습니다 | 검증된 백업의 원본 파일을 복구하거나, 최신 코드로 사본에서 분석을 재개하세요. `run_state.json`의 해시를 직접 바꾸지 마세요. |
| 예측 단계 기록이 손상되었습니다 | 같은 분석의 백업에서 `run_state.json`을 복구하세요. 손상된 사본도 진단용으로 보관하세요. |
| 예측 단계 기록이 비어 있습니다 | NanoCoFold를 업데이트하고 사본에서 분석을 재개한 뒤 점수를 다시 계산하세요. 이전 ColabFold 실행은 이 기록을 누락할 수 있었습니다. 파일만 보고 실행 출처를 추정하지 않습니다. |

`score`가 결과를 변경하기 전에 거부됐고 기존 표와 발행 상태가 그대로라면, 완료된 결과는 유지되며 `report`도 사용할 수 있습니다. 결과 변경이 이미 시작됐다면 미완료 상태를 유지하고, 복구 전까지 보고서 재생성을 차단합니다.

예측 단계 기록이 없는 구형 폴더는 해당 모드의 기본 예측 단계를 사용합니다. `screen.boltz2_rescore_top`을 켰다는 이유만으로 과거 Boltz-2 재평가 폴더를 선택하지 않습니다. 따라서 구형 폴더를 재점수화하면 예전 버전과 다른 단계의 결과가 사용될 수 있습니다. 새 평가를 직접 실행하기 전에는 기존 파일과 선별 기준이 그대로 유지됩니다. 비교할 원본 보고서를 따로 보관하세요.
