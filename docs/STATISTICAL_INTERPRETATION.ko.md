# 점수와 통계 요약 읽기

[English](STATISTICAL_INTERPRETATION.md)

NanoCoFold는 예측 구조를 살피고 다음 검토·실험의 우선순위를 정하는 도구입니다.
점수는 보정된 결합확률이나 친화도·KD·발현·생물학적 특이성의 측정값이 아닙니다.

| 기록된 결과 | 해석 |
| --- | --- |
| 예측 완료 | 계산 단계가 끝났다는 뜻입니다. 실패와 미평가 관측을 따로 확인합니다. |
| 적격·선별 | 기록된 소프트웨어 품질·선별 기준을 통과했습니다. 실제 결합은 별도 실험 endpoint입니다. |
| 종합점수 | 기록된 엔진과 후보 집합 안의 상대 점수입니다. 후보 추가나 가용 지표 변경으로 원점수가 같아도 종합점수가 달라질 수 있습니다. |
| 엔진 일치·seed 범위 | 계산의 일관성·변동성입니다. seed·모델·잔기·접촉 수는 독립적인 생물학적 반복 수가 아닙니다. |
| 전장형·절단형 특이성 비교 | 모든 기대 관측과 승인된 비교조건의 검증이 필요합니다. 출처 미확인 과거 기록은 읽을 수 있지만 비교 완료의 근거가 되지 않습니다. |

실제 엔진별 후보 집합의 순위 정책에서 적용·제외 가중치와 보류 관측을 확인하세요.
서로 다른 엔진의 점수를 합쳐 전체 순위를 만들지 않습니다. 일부 후보만 Boltz로
재평가하면 1차 점수로 고른 후보와 나머지 후보가 다른 엔진에 배정됩니다.
엔진별로 순위를 나누어도 같은 후보를 평가한 엔진 성능 비교가 되는 것은 아닙니다.

특이성의 `delta_ipsae`는 절단형 중앙값에서 전장형 중앙값을 뺀 값입니다.
같은 seed별 차이의 중앙값과 다릅니다. 원관측과 비교조건을 함께 확인하세요.

특이성을 재분석한 뒤에는 원래 예측 설정과 현재 평가 기준을 구분하세요.
현재 기준은 원래 예측과 정확한 산출물 표에 연결된 평가 기록으로 검증합니다.
기록이 없거나 일치하지 않으면 현재 기준은 미확인입니다. 이때 원래 임계값을
재분석에 적용한 임계값처럼 표시하지 않습니다.

과거 벤치마크의 `permutation_pvalue_rank1`과
`permutation_pvalue_all_positives_top_k`는 무작위 순위의 기준 확률입니다.
관측 순위나 AUC의 검정값이 아닙니다. 현재의 관측 순위 요약은 유한한 라벨 관측의
집합, 동점 경계, 귀무모형, 다중검정 처리 여부를 명시합니다. 반올림된 과거 표로
원래 전체 정밀도 점수를 복원할 수 없습니다. 기준 양성·가정한 decoy 라벨은
실측 비결합이나 새로운 표적에 대한 성능을 검증하지 않습니다.

실험 성능을 주장하려면 유리한 엔진·임계값을 고르기 전에 assay endpoint,
항원·항체 construct, 실측 양성·음성, 독립 표적·서열 계통, 검증 정책을 정합니다.
실험 분모와 불확실성은 모델 수와 따로 보고하세요. 원점수는 p-value가 아니며,
다중검정 보정을 덧붙여 결합 근거로 바꿀 수 없습니다.
