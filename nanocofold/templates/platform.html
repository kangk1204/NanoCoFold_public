새 분석 시작

입력을 검토하고 실제 적용 설정을 확인한 뒤 실행하세요. CPU 데모는 합성 결과로 사용 흐름을 연습합니다.

1. 모드와 입력

실험 구조의 체인과 원본 잔기 번호를 보존합니다.

MolStar · 진행할 체인 선택

Ctrl+클릭: 표적 체인 선택 · Ctrl+Shift+클릭: 파트너 추가·해제. Mac에서는 ⌘ 키도 사용할 수 있습니다. 표적은 한 체인, 파트너는 여러 체인을 선택할 수 있습니다.

보존할 파트너 체인

단백질 입력 판정

파일에 기록된 전체 서열을 자동으로 채웁니다. X 등 불명확한 위치와 실제 construct를 확인하세요. 정보가 없는 체인은 확인한 전체 서열을 입력하세요. 알려진 잔기의 변경이나 모호한 대응은 차단합니다.

원본 좌표는 참조로 보존합니다. 새 예측은 단백질 서열 모델이며 수정 잔기·chromophore·당질·리간드·핵산·막 환경을 재현하지 않습니다.

원본 좌표에서 Hotspot 검토

원본 번호·노출도 대응표

서열 입력의 구조와 hotspot은 예측됩니다. 기본 MSA는 empty이며 외부 서버로 서열을 보내지 않습니다.

표적 분석 구간 · Hotspot 제외 영역

비워 두면 전체 표적을 분석합니다. 좌표 사용은 관측 서열, 새 구조 예측·FASTA는 검토한 전체 서열의 1-based 위치입니다.

제외 구간은 좌표·접촉 평가를 유지합니다. 분석 구간 선택은 실제 표적 construct를 절단합니다. 도메인·태그 이름은 연구자가 지정하며 자동 확정하지 않습니다.

아래 고급 설정에서 AntiFold를 끄면 WT 구조 없이 평가할 수 있습니다.

2. 설정 검토와 실행

연구자 탐색은 RF2·ESM 사전 탈락을 해제하고 hotspot restraint·랭킹 가중치를 끕니다. design은 1,000개 백본을 생성하고 최대 500개 복합체를 평가합니다. mature는 최대 500개와 WT 대조군을 평가합니다. screen은 입력 라이브러리 전체를 평가합니다. 품질 판정·충돌·개발가능성 경고를 유지하며 결과는 전체 후보를 표시합니다. design 구조 생성은 선택한 hotspot에 조건화됩니다. 후보 수가 늘면 계산 시간도 늘어납니다.

입력·설정·도구·가중치·MSA 정체성이 확인된 완료 결과만 재사용합니다. 공개 API의 변경 가능한 DB는 자동으로 동일 실행으로 간주하지 않습니다.

고급 설정 · YAML 가져오기

서로 다른 조건의 점수는 비교 시 개별로 표시합니다. 입력 검토가 확정한 표적·hotspot은 고급 설정으로 덮어쓰지 않습니다.

03 후보 비교

            
예측 신뢰도와 지정 위치 충족은 별개입니다. hotspot 접촉 수와 판정을 함께 확인하세요. 동일 엔진·실행 조건 안에서 지표를 비교하세요. 정렬은 탐색 순서이며 엔진을 합친 최종 순위가 아닙니다.

            

              
              
            

            

              
              
              
            

            
Hotspot 후필터는 기본 해제입니다. 켜면 미지정·접촉률 미평가·번호 대응 실패·기록 불일치 후보는 표시하지 않습니다. 접촉률만 저장된 이전 결과는 기록된 비율로 필터하며 상세 접촉 수·판정은 미평가로 남습니다.
              기존 결과의 적격 판정과 선별 목록은 보존하며, 품질 적격은 기록된 판정에서 hotspot만 제외한 탐색 값입니다.

환경과 설치

        

          계산은 Linux x86_64 NVIDIA GPU 호스트에서 실행합니다. 연구자 PC는
          브라우저와 SSH 포트포워딩으로 접속합니다.
        

        

          
설치 프로필

          

            core는 본체와 CPU 데모, design은 RFantibody·BoltzGen과 Boltz-2·Chai-1,
            screen은 보유 VHH 비교, mature는 변이 평가 환경을 준비합니다.
            네 엔진 독립 비교에는 design 또는 screen 설치 후 colabfold와 opendde를
            각각 추가하세요. all에도 이 두 선택 엔진은 포함되지 않습니다. 대형 MSA DB는 선택 설치입니다.
          

          

            
          

          

            설치·점검은 작업 탭에서 다운로드 진행과 로그를 확인합니다. 실패한
            필수 엔진이 있으면 실제 분석을 시작하지 않습니다.
          

          

        

        

          
시작 안내

          
작업 공간: 

          
nanocofold init --workspace ~/nanocofold-workspace
nanocofold setup --workspace ~/nanocofold-workspace --profile all
nanocofold setup --workspace ~/nanocofold-workspace --profile colabfold
nanocofold setup --workspace ~/nanocofold-workspace --profile opendde
nanocofold serve --workspace ~/nanocofold-workspace --no-browser
